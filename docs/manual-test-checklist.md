# GoRun 手动测试清单

> 主线为 `rs/`（Rust + Slint），C++ 原版已移除，本清单仅覆盖 Rust 主线。
> Rust 主线同时提供**右键"上移/下移"**与**拖拽排序**（F2-1，DragArea/DropArea）两种排序方式，二者并存。本清单按 Rust 实际实现编写。
>
> **勾选说明**：2026-11-24 已按本清单对 `rs/` 全部代码链路完成一轮静态审查（见文末审查记录），`[x]` 表示对应代码链路审查通过；发布前仍需在 Windows 真机按本清单做人工验收。

## 验收判定口径

每条用例默认按以下三层判定，**任一层不通过即判定失败**：

1. **功能正确**：操作达到预期结果（数据/状态变化符合预期）。
2. **界面正常**：控件显示、布局、对齐、颜色、图标、文案无错位、截断、重叠。
3. **交互顺畅**：无卡顿、无闪烁、焦点与键盘行为正确、无报错弹窗或崩溃。

标注 **界面检查** 的条目需额外核对该项视觉表现；未标注条目同样受总则约束。
