# GoRun - 极速启动工具

**GoRun** 是一款专注于"快速启动"的纯粹工具。

## 特色亮点

**现代化架构** - 拥抱前沿技术栈，以超前架构定义性能，深度融合新系统特性。

**极致的快** - 100% 原生开发，毫秒级启动、即时响应。无 WebView，无 Electron，性能与体验全面领先。

**低能耗** - 深度优化底层架构，实现极低资源占用，长时间运行依然轻盈高效。

## 已实现功能

> 主线为 `rs/`（Rust + Slint）。

### 核心功能
- 窗口框架（Slint 原生渲染，无 WebView/Electron）
- 拖放添加文件/快捷方式
- 分类管理（创建、编辑、删除；右键上移/下移排序 + 拖拽排序）
- 项目管理（添加、编辑、删除；右键上移/下移排序 + 拖拽排序、移动到分类）
- 双击运行 / 管理员运行
- 全局快捷键唤醒/隐藏主窗口（默认 Ctrl+/）
- 设置界面（菜单"设置…"）：自定义应用背景图（png/jpg，暗化遮罩可调）
- 托盘图标（显示/隐藏、开机自启、跟随鼠标）

### 数据管理
- JSON 格式存储配置和数据（便携优先，回退系统数据目录）
- 图标缓存系统（FNV-1a64 哈希命名，编辑自动失效）
- 配置持久化（窗口位置、大小、主题、跟随鼠标等）
- 数据安全（原子写 + 单份备份 + 损坏隔离留证，孤儿条目自动归首分类）

### UI 组件
- 分类侧边栏（含计数徽章、选中指示条）
- 项目网格/列表视图切换
- 工具行（搜索框 + 视图/主题/汉堡三图标按钮）
- 汉堡菜单（新建/删除/重命名/热键/视图/主题/跟随鼠标/自启/导入导出/设置/关于/退出）
- Toast 提示（右下角，成功/错误，替代状态栏）
- 编辑对话框
- 主题系统（深色/浅色，设计令牌驱动）
- 搜索（子串 + 拼音首字母/全拼，按使用次数排序）
- 多语言（固定简体中文；v2 决策不再支持切换）

## 构建

> 主线构建（`rs/`，Rust）。

### 环境要求

- Rust 1.95+（MSRV 由依赖链决定：slint 1.19 及 backend 依赖要求 rustc 1.95）
- Cargo
- Windows SDK（for windows crate）

### 构建步骤

```bash
cd rs

# Debug 构建
cargo build

# Release 构建
cargo build --release

# 运行单元测试
cargo test --lib

# 运行 GUI 集成测试（需要 xvfb 或显示服务器）
cargo test
```

### 依赖项

| 依赖 | 版本 | 用途 |
|-----|------|------|
| slint | 1.19.1 | UI 框架 |
| serde / serde_json | 1.x | JSON 序列化 |
| dirs | 7.x | 系统目录 |
| image | 0.25 | 图标处理 |
| pinyin | 0.10 | 中文拼音搜索 |
| windows | 0.62 | Windows API（仅 Windows 目标） |

## 数据存储

> 主线（`rs/`，Rust）：**便携优先**——配置 `config.json` 与图标缓存 `icons/` 均位于可执行文件所在目录（`%EXEDIR%`）；仅当 exe 目录不可写时回退系统数据目录（Windows 为 `%LOCALAPPDATA%/GoRun`）。首次运行时自动创建目录和默认配置文件，并迁移旧版 `%APPDATA%/GoRun` 数据（只复制不删源）；空占位旧配置（所有条目无 target）不迁移。

## 参数变量

GoRun 支持 Windows 环境变量同时并内置参数变量：

| 变量名 | 说明 | 支持版本 |
|-------|------|---------|
| `%mp%` | 当前目录 | 1.0.0.1+ |
| `%mr%` | 当前盘符 | 1.0.0.1+ |
| `%so%` | 搜索参数 | 2.8.0.0+ |
| `%so-url%` | 搜索参数 URL 编码 | 2.8.0.0+ |
